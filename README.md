# open-meteo-weather-shortcut-ios
iOS快捷指令，基于Open-Meteo，查询实时天气情况。

## 功能
- 自动定位，获取实时气温、体感温度、相对湿度、降水量
- 风速、阵风、风向自动转为中文方位
- 云量、☀紫外线指数+防晒等级提示
- 天气代码自动翻译成中文天气描述（晴/雨/雷暴等）

## API信息
数据源：Open-Meteo（完全免费，无Key、无账号）
> Open-Meteo官网：https://open-meteo.com/

## 安装方法
*点击链接导入快捷指令：https://www.icloud.com/shortcuts/d6bd6d407cf44c24a5016bf0a944de5f

1. 下载 `实时天气.shortcut`
2. 在iPhone「文件」App点击该文件，自动导入快捷指令
3. 首次运行：允许位置权限，允许不受信任快捷指令
